# Train Set

## What is Train Set

Its a train set that you can make using your 3d printer! The set consists of 3 different print in place wheel chassis along with 2 different train bogies (train engine and a cargo chassis)

## How do I use it?

Simple download all the print files given above in the github repo and print them with default settings (Supports on with tree). After printing, assembly should be fairly intuative, the engine should be the hardest to assemble amongst all as it requires you assembling the railings which can get difficult. 

## Why did you make this?

I made this to serve as a project to learn CAD and different techniques that can be used in 3d printing like print in place mechanisms the wheel chassis use
